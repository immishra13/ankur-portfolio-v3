# Ankur Mishra — Portfolio v3

**Concept: Madhubani roots, modern code.** A recruiter-first portfolio that proves instead of claiming.

Live: https://immishra13.github.io/ankur-portfolio-v3/

## What makes it different

- **The avatar watches you.** An illustrated portrait of Ankur in Maithili kurta-paag-dhoti follows the visitor's cursor — pupils move, the figure leans toward the pointer, and tapping it cycles through spoken lines. Motion is transform/opacity only and respects `prefers-reduced-motion`.
- **The work reshapes for the recruiter.** Pick a role — AI & ML, Backend, Full-stack, Events — and the project grid filters to what that hire needs, with a live count announced to screen readers.
- **Two worlds, one person.** A Tech / Events toggle with the matching CV for each side of Ankur's career.
- **Proof, not promises.** Every project is live or linked: FixMateHub (1000+ customers), AwaazRoute (live demo), RTI Black Hole, Financial Complaint Classifier, Preview Cloud, E-WasteChain, YOLO vision. Numbers are real: Sem 6 SGPI 8.70, NPTEL AI 96, 50+ events run.

## Files

- `index.html` — content, metadata (canonical + Open Graph + Twitter + JSON-LD Person)
- `styles.css` — one design system, plain CSS, responsive
- `app.js` — avatar follow, role filter, world toggle, counters, reveal
- `avatar.png` — Ankur's Maithili-look avatar, transparent background
- `og-image.png` — 1200×630 share image
- `Ankur_Mishra_Tech_Resume.pdf` — Tech CV
- `Ankur_Kumar_Mishra_Event_Management_CV.docx` — Event Management CV
- `DESIGN.md` — the design language of this site

## Stack

Plain HTML, CSS and JavaScript. No framework, no build step. Hosted free on GitHub Pages.
